JOHN EDRIAN — BEYOND THE ORDINARY
===================================

A fresh one-page personal portfolio built with HTML, CSS, and vanilla JavaScript.
This version is intentionally different from the previous galaxy portfolio: editorial typography,
a clear layout, short storytelling sections, a compact skills toolkit, a family/interest section,
theme switching, responsive navigation, and a 15-second stardust mini-game.

HOW TO RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or double-click index.html to open it in a browser.
4. Try the Theme button, mobile menu, and Start side quest game.

FILES
- index.html : page structure and personal content
- style.css  : visual design, responsive layout, animations
- script.js  : theme toggle, navigation, scroll reveals, mini-game
- assets/    : reused photos from the provided website project

PERSONAL CONTENT
Some details are based on the portfolio context available. Review the text before evaluation and edit
anything you want to make more personal or accurate. The page does not use a backend or collect data.


MUSIC VIDEO
The butterflies lyric video is included locally in assets/butterflies-lyric-video.mp4. Keep the assets folder with index.html, style.css, and script.js when moving or sharing the website. Open index.html in a modern browser; click the music section and use the built-in video controls.
